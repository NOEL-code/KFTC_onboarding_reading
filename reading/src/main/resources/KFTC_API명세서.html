PUT /api/reports/{reportId} 독후감 수정 (재제출) 기능 1.4.1 / 1.4.3

Request — multipart/form-data

필드타입필수설명

fileFile선택변경할 hwp 파일
본인 사번이 일치하지 않으면 403 Forbidden 반환. 보완 상태의 독후감은 재제출 시 상태가 "제출"로 변경됩니다.

Response — 200 OK

{ "reportId": 1, "status": "제출", "updatedAt": "2026-03-25T14:20:00" }

Status Codes

200 수정 성공 400 유효하지 않은 파일 403 본인 독후감 아님 404 독후감 없음
