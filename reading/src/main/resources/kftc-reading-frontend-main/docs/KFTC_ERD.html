KFTC 독후감 제출 시스템 — ERD (Entity Relationship Diagram)

Figma 디자인 및 기능 명세서 기반 데이터 모델링

ER 다이어그램

erDiagram ADMIN { bigint id PK varchar login_id UK varchar password varchar name timestamp created_at timestamp updated_at } USER { bigint id PK varchar employee_no UK varchar name varchar team timestamp created_at timestamp updated_at } READING_COURSE { bigint id PK varchar name date start_date date end_date text description varchar status timestamp created_at timestamp updated_at } COURSE_ENROLLMENT { bigint id PK bigint course_id FK bigint user_id FK timestamp created_at } BOOK_REPORT { bigint id PK bigint enrollment_id FK varchar title varchar file_name longblob file_data bigint file_size varchar status timestamp submitted_at timestamp updated_at } REPORT_TEMPLATE { bigint id PK varchar file_name longblob file_data bigint file_size bigint uploaded_by FK varchar status timestamp uploaded_at timestamp updated_at } NOTICE { bigint id PK varchar title text content bigint created_by FK timestamp created_at timestamp updated_at } ADMIN ||--o{ REPORT_TEMPLATE : "업로드" ADMIN ||--o{ NOTICE : "작성" USER ||--o{ COURSE_ENROLLMENT : "신청" READING_COURSE ||--o{ COURSE_ENROLLMENT : "포함" COURSE_ENROLLMENT ||--o| BOOK_REPORT : "제출"

관계 정의

ADMIN 1 ──── 0..N REPORT_TEMPLATE 관리자가 독후감 양식을 업로드/관리
ADMIN 1 ──── 0..N NOTICE 관리자가 공지사항을 작성
USER 1 ──── 0..N COURSE_ENROLLMENT 사용자가 독서과정에 신청 (반기별 복수 참여 가능)
READING_COURSE 1 ──── 0..N COURSE_ENROLLMENT 하나의 독서과정에 여러 사용자 등록
COURSE_ENROLLMENT 1 ──── 0..1 BOOK_REPORT 과정 참여자 당 독후감 1건 제출 (파일 1개 제한)

엔티티 상세 명세

ADMIN 관리자

관리자 로그인 및 시스템 운영 (아이디/비밀번호 인증)

컬럼타입제약설명
idBIGINTPK관리자 ID
login_idVARCHAR(50)UK로그인 아이디
passwordVARCHAR(255)NOT NULL비밀번호 (bcrypt 암호화)
nameVARCHAR(50)NOT NULL관리자 이름
created_atTIMESTAMP생성일시
updated_atTIMESTAMP수정일시

USER 사용자

독서과정 참여자 (엑셀 일괄등록 또는 개별 추가)

컬럼타입제약설명
idBIGINTPK사용자 ID
employee_noVARCHAR(20)UK사번
nameVARCHAR(50)NOT NULL이름
teamVARCHAR(50)NOT NULL팀 (IT개발팀, 인사팀 등)
created_atTIMESTAMP생성일시
updated_atTIMESTAMP수정일시

READING_COURSE 독서과정

반기별 독서경영 과정 (진행중/완료 상태)

컬럼타입제약설명
idBIGINTPK과정 ID
nameVARCHAR(100)NOT NULL과정명 (예: 26년 상반기)
start_dateDATENOT NULL시작일
end_dateDATENOT NULL종료일
descriptionTEXT과정 설명
statusVARCHAR(20)NOT NULL진행중 / 완료
created_atTIMESTAMP생성일시
updated_atTIMESTAMP수정일시

COURSE_ENROLLMENT 과정 신청

사용자-과정 간 다대다(M:N) 연결 테이블

컬럼타입제약설명
idBIGINTPK신청 ID
course_idBIGINTFK NOT NULL독서과정 ID
user_idBIGINTFK NOT NULL사용자 ID
created_atTIMESTAMP등록일시

BOOK_REPORT 독후감

과정 참여자가 제출하는 독후감 (hwp 파일 1개 제한)

컬럼타입제약설명
idBIGINTPK독후감 ID
enrollment_idBIGINTFK UK과정신청 ID (1:1)
titleVARCHAR(200)독후감 제목
file_nameVARCHAR(255)원본 hwp 파일명
file_dataLONGBLOBhwp 파일 바이너리 데이터
file_sizeBIGINT파일 크기 (bytes)
statusVARCHAR(20)NOT NULL미제출 / 제출 / 승인 / 보완
submitted_atTIMESTAMP제출일시
updated_atTIMESTAMP수정일시

REPORT_TEMPLATE 독후감 양식

모든 과정에 공통 적용되는 한글(hwp) 양식 파일

컬럼타입제약설명
idBIGINTPK양식 ID
file_nameVARCHAR(255)NOT NULL원본 hwp 파일명
file_dataLONGBLOBNOT NULLhwp 양식 파일 바이너리 데이터
file_sizeBIGINT파일 크기
uploaded_byBIGINTFK업로드한 관리자
statusVARCHAR(20)NOT NULL사용중 / 미사용
uploaded_atTIMESTAMP업로드 일시
updated_atTIMESTAMP수정일시

NOTICE 공지사항

사용자 메인 페이지에 표시되는 공지사항

컬럼타입제약설명
idBIGINTPK공지 ID
titleVARCHAR(200)NOT NULL제목
contentTEXT내용
created_byBIGINTFK작성한 관리자
created_atTIMESTAMP작성일시
updated_atTIMESTAMP수정일시
